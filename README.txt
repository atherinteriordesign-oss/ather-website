ATHER Website — Front-End Starter

Files:
- index.html — complete single-page website with HTML, CSS and JavaScript in one file.

How to run:
1. Open index.html in Chrome, Edge or Firefox.
2. For development, use VS Code + Live Server if preferred.

Before launch:
- Replace the placeholder phone and WhatsApp number +201000000000 in index.html.
- Replace demo stock images with real ATHER project images.
- Connect the contact form to a backend, Formspree, EmailJS, CRM, or custom API.
- Add real projects, testimonials, project statistics and office address when available.
